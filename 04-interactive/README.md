# 04-interactive — 算法知识图谱交互式 DAG 总览

单文件自包含交互图（`index.html`），内嵌 DAG 数据，支持 `file://` 直接打开，无需服务器。

## 文件结构

```
04-interactive/
├── index.html        # 主文件：内嵌数据 + 样式 + 脚本（自包含）
├── vendor/
│   ├── cytoscape.min.js        # cytoscape.js 3.30.2
│   └── cytoscape-dagre.min.js  # dagre 布局插件 3.0.0
└── README.md         # 本说明
```

## 数据规模

- **60 组** 知识域分组（G-A-1 … G-E-10）
- **372 个** 知识点节点，覆盖 4 个学习阶段（basic/intermediate/advanced/frontier）
- **318 条** 边，4 种关系：前置(prerequisite) / 变体(variant) / 组合(combination) / 共现(cooccurrence)
- 优先级 4 档：P0(94) / P1(113) / P2(116) / P3(49)

## 三级下钻

1. **组级视图**（默认）：60 个彩色组节点，颜色按域（同域同色调、组间明度渐变）。点击组 → 下钻组内 DAG。
2. **组内 DAG**：本组成员彩色实心，跨组关联节点灰显（stub），stub 也可点击跳转。节点按组内顺序排列，可连续浏览（组内顺序即 `group.node_ids` 顺序）。
3. **节点页**：点击节点（本组成员或 stub）跳转 `../02-node-pages/{id}.html`。

- 顶部「← 返回组级」按钮或面包屑返回一级。
- 右下侧「组配色」列表点击任一组可直接下钻定位。

## 视图切换

顶部按钮（组级 / 下钻视图均可用）：

| 视图 | 行为 |
|------|------|
| **完整** | 全部 60 组 / 372 节点 / 318 边 |
| **冲刺** | 仅 P0+P1 核心节点与核心-核心边；组级视图下无 P0/P1 的组淡显，组间边只保留核心经由端点 |
| **高亮** | 完整图，P0 节点红色加粗边框；组级视图下含 P0 的组红框并标注 `P0:核心数/总数` |

三视图共用同一套 DAG 数据，用 `priority` 字段过滤/高亮，切换即时生效。

## 学习路径视图

顶部「学习路径」按钮切换：

- **按域**：17 个域聚簇节点，域间边按组间边聚合。
- **按学习阶段**：4 个 stage 层节点（basic → intermediate → advanced → frontier）；点击某层下钻该层全部节点 DAG，便于按阶段连续学习。

再点一次「学习路径」退出回到组级视图。

## 搜索

顶部搜索框输入关键词，实时高亮匹配节点（节点名或 id 包含即命中），非匹配节点淡显。输入清空恢复。

## Hash 路由

支持 `#G-A-6` 直达组内 DAG、`#sort-intro` 直达节点所在组并高亮该节点。用于跨页引用与收藏。

## 边类型图例

| 类型 | 样式 | 含义 |
|------|------|------|
| prerequisite | 蓝色实线加粗 | 前置依赖 |
| variant | 金色虚线 | 变体实现 |

## 技术说明

- 渲染：cytoscape.js + dagre 分层布局（LR 方向）
- 数据：从 `01-dag-data/algorithm-dag.json` 预处理后内嵌于 `index.html` 的 `const DATA`（组级聚合边在预处理阶段生成）
- 交互：拖拽平移、滚轮缩放（0.05–5x）、点击下钻
- 响应式：窄屏下侧栏自动收窄，适配移动端

## 移动端

宽度 < 768px 时：侧栏压缩至 220px、标题与提示精简、详情面板宽度 86vw。触屏支持单指拖拽 / 双指缩放。

## 维护

- 数据变更：重新生成 `01-dag-data/algorithm-dag.json` 后，需同步重建 `index.html` 内嵌的 `const DATA` 段（节点/组/边/层/组间聚合边）。组间聚合边生成逻辑：跨组边按「源组→目标组」聚合，每条保留一个经由端点对（`viaFrom`/`viaTo`），供冲刺视图过滤核心集使用。
